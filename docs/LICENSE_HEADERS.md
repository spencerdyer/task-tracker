# Licence headers

The project is licensed under the Apache License 2.0 (`LICENSE`, `NOTICE`). New source files may
start with this short header (it isn't required; the `LICENSE` file covers the whole repository):

Python:

```python
# SPDX-License-Identifier: Apache-2.0
# Copyright 2026 The Task Tracker authors
```

TypeScript / JavaScript / CSS:

```ts
// SPDX-License-Identifier: Apache-2.0
// Copyright 2026 The Task Tracker authors
```

Files copied from another project keep that project's licence and notice. Name the source and
its licence in `docs/THIRD_PARTY.md`.
